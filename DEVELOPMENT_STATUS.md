## Bugs fixed this session

- `useOfflineWrite` no longer adds `user_id` to inserts for tables that do not own a `user_id` column (`crop_activities`). Ownership is via `farm_crops → farms`.
- `downloadCsv` generic widened so typed domain rows (`Expense`, `IncomeRecord`) compile without unsafe casts.
- `MarketPage` replaced `Array.prototype.at` (not in the configured TS lib) with an index-based latest-date lookup.
- `SettingsPage` imported `formatFetchedAt` from `@/lib/utils`; it lives in `@/lib/weather`. Fixed.
- `climate` Edge Function used camelCase `startYear`/`endYear` keys against snake_case DB columns, so cache reads and writes silently failed. Changed to `start_year`/`end_year`; cache-write errors are now logged. Cache round-trip verified.
- Removed a stale 175-byte malformed `climate_cache` row that lacked `months`.
- Recommendation test fixtures now use the real domain fields (`min_ph` / `max_ph`,
  `cost_min_per_acre` / `cost_max_per_acre`, climate humidity/solar radiation,
  `MarketPrice.source` / `fetched_at`), so `tsc -b` type-checks tests cleanly while
  `npm test` still passes all 30 tests.

## Known issues / limitations

1. **data.gov.in HTTP 429**: the public sample key is rate-limited. Market UI degrades honestly, keeps saved snapshots and supports official CSV import. No data is fabricated.
2. **IMD**: no stable public JSON API exists. FarmDesk links to official IMD bulletins and labels forecast alerts as FarmDesk-computed, not IMD warnings.
3. **AI**: no `AI_API_KEY`; the rules engine answers from the same read-only tools and is labelled. This is intentional, not a failure.
4. **Offline**: only expenses, income, crop activities and tasks are queued. Crops, soil and settings require a connection.
5. **`psql` on host absent**; use `docker exec supabase_db_farmdesk psql -U postgres -d postgres`.
6. **`supabase migration list`** fails because the project is not linked; use `npx supabase migration up --local`.
7. **Manual browser smoke test is still pending.** Automated tests cover logic, RLS and live integrations, but not rendered UI behaviour.
8. **Main JS bundle is ~2.2 MB minified (633 kB gzipped).** It is intentionally precached so the offline shell works; route-level code splitting is a future optimisation.
9. **Git is not initialised**; there is no commit history for rollback.
